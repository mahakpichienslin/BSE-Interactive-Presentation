# BSE Control Box Training Prototype

Interactive browser prototype based on the BSCB-004AL-V3 control box image and supplied training/manual PDF.

Open `index.html` in a browser, or upload the folder contents to GitHub Pages.

Training interactions included:
- Main breaker ON/OFF
- 10-second startup system check
- PHOTO / MANUAL mode
- Ambient-light simulation with 31.5 / 125 Lux thresholds
- Lamp 1–3 load-failure simulation
- Alarm state display
- Lamp-by-Lamp / Spare function toggle
- Flash-rate control range 10–60 FPM

Note: this is a training UI prototype. Final operational logic should be validated against the production firmware/manual before customer deployment.
