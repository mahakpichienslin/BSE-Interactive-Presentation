# BSE Roof Interactive Presentation

Prototype เว็บสำหรับนำเสนอ Concept การติดตั้ง Aviation Obstruction Light บน Roof Plan

## Files
- `index.html`
- `style.css`
- `script.js`
- `assets/roof-plan.png`

## Run locally
ดับเบิลคลิก `index.html` ได้เลย หรือเปิดด้วย VS Code Live Server

## Publish with GitHub Pages
1. Create a new GitHub repository
2. Upload all files in this folder
3. Go to **Settings → Pages**
4. Under **Build and deployment**, choose **Deploy from a branch**
5. Select `main` and `/root`
6. Save and wait for the GitHub Pages URL

## Important
ตำแหน่งไฟ 6 จุดในเวอร์ชันนี้เป็น Concept เพื่อทำ Interactive Presentation เท่านั้น
ยังไม่ใช่การยืนยันตำแหน่งติดตั้งทางวิศวกรรม
